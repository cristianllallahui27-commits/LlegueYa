Arquitectura de LlegueYa

Siete servicios independientes. Las vistas previas son públicas y las fichas detalladas requieren sesión. Las consultas usan REST y los cambios se propagan mediante eventos durables.

Portadas públicas y galerías autorizadas; documentos privados separados. El modelo C4 detalla las relaciones de comunicación entre los servicios. Diseño documental, sin implementación.
