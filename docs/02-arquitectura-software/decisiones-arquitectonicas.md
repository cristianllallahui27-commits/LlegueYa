# Decisiones arquitectónicas

El [registro ADR-001 a ADR-027](../01-analisis-de-sistema/07-decisiones-arquitectonicas.md) reúne las decisiones de distribución, Clean Architecture, datos, acceso, comunidad, categorías y publicidad. Se mantiene una única definición de cada decisión.
Las decisiones detalladas y alternativas tecnológicas se explican en el [SDD](../05-sdd/02-arquitectura-y-decisiones.md).
