# 04 - Atributos de calidad

Escenario base: en Semana Santa, Carnavales o el Vilcas Raymi, muchos turistas consultan al mismo tiempo sitios, mapas, proveedores, reseñas, fotos y libros, y suben nuevo contenido.

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | Las consultas de sitios, mapas, reseñas y galerías de fotos deben responder rápidamente, incluso con muchos usuarios concurrentes. |
| AC02 | Disponibilidad | El sistema debe permanecer disponible en las fechas de festividades (Semana Santa, Carnavales, Vilcas Raymi). |
| AC03 | Escalabilidad | El sistema debe soportar el aumento de visitas en festividades sin afectar significativamente su funcionamiento. |
| AC04 | Seguridad | Solo se deben redirigir enlaces de venta verificados por el administrador, y los datos de los usuarios deben estar protegidos frente a accesos no autorizados. |
| AC05 | Confiabilidad de la información | Solo deben mostrarse proveedores con documentación vigente, y los comentarios y fotos deben estar asociados a un usuario registrado. |
| AC06 | Usabilidad | El turista, nacional o extranjero, debe poder consultar, ubicarse en el mapa y usar el chatbot de forma sencilla desde el navegador. |
| AC07 | Mantenibilidad | El sistema debe organizarse en módulos independientes, para poder cambiar una funcionalidad sin afectar a las demás. |
