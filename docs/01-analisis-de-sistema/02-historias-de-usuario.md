# 02 - Historias de usuario

Formato: Como [actor], quiero [acción], para [beneficio].

| ID | Historia de usuario |
|---|---|
| HU01 | Como turista, quiero registrarme e iniciar sesión, para comentar, puntuar y recibir notificaciones. |
| HU02 | Como turista, quiero consultar los sitios arqueológicos con su distancia, tiempo de viaje y forma de acceso, para planificar mi visita. |
| HU03 | Como turista, quiero ver en el mapa dónde se venden las entradas de un sitio y acceder a su página de venta virtual, para comprar en un lugar confiable. |
| HU04 | Como turista, quiero consultar hospedajes, restaurantes y transportistas verificados con sus precios y ubicación, para elegir opciones confiables. |
| HU05 | Como turista, quiero ver la puntuación y los comentarios de un servicio, para decidir con la experiencia de otros viajeros. |
| HU06 | Como turista, quiero puntuar y comentar un servicio que usé, para compartir mi experiencia. |
| HU07 | Como turista, quiero publicar fotos de mi experiencia, para compartirla con otros viajeros. |
| HU08 | Como turista, quiero ver las fotos de experiencias de otros turistas, para conocer cómo es el lugar o servicio. |
| HU09 | Como turista, quiero leer historias y ver fotografías de personas del lugar o de la festividad, para conocer su cultura. |
| HU10 | Como turista, quiero consultar libros con información turística del lugar o la festividad, para informarme antes de viajar. |
| HU11 | Como turista, quiero recibir una notificación cuando se publique una nueva historia, fotografía o libro, para enterarme del nuevo contenido. |
| HU12 | Como turista, quiero ver un paquete turístico (movilidad, hospedaje y restaurantes) con proveedores verificados, para organizar mi viaje en un solo lugar. |
| HU13 | Como turista, quiero que el chatbot me recomiende un paquete, precios de hospedaje y restaurantes o transportistas cercanos según mi presupuesto, para decidir con confianza. |
| HU14 | Como turista, quiero que el chatbot me indique el mejor mes del año para viajar, para elegir entre temporada seca o una festividad. |
| HU15 | Como proveedor, quiero registrar mi oferta y mis documentos, para aparecer en la plataforma y en los paquetes. |
| HU16 | Como administrador, quiero verificar los documentos de los proveedores, para que solo aparezcan opciones confiables. |
| HU17 | Como administrador, quiero registrar sitios con sus puntos y enlaces de venta y su ubicación, para guiar al turista al lugar correcto. |
| HU18 | Como administrador, quiero publicar y gestionar historias, fotografías y libros, para mantener actualizado el contenido turístico. |
| HU19 | Como administrador, quiero moderar reseñas y fotos de los usuarios, para mantener contenido adecuado. |
